Repository, Python/frontend tooling, CI, Docker, docs.

Candle schema, ingestion adapter, validation, dataset versioning.

## Phase 2 Features
Indicators, statistics, feature registry, leakage tests.

Baseline, tree models, calibration, registry metadata.

Event engine, simulator, metrics, walk-forward, sensitivity.

Risk policy, paper portfolio, audit trail.

FastAPI, Next.js, auth, charts.

## Phase 7 Agents
Typed tools, orchestrator, research/backtest/experiment agents.

## Phase 8 MLOps
Model registry, monitoring, drift, retraining proposals.

## Phase 9 Portfolio release
Architecture diagrams, demo, research report, deployment guide.
