# Definition of Done

A feature is complete only when:

## Product
- requirement mapped
- acceptance criteria defined
- failure states defined

## Engineering
- typed interfaces
- modular design
- no unnecessary coupling
- configuration separated

## Testing
- unit tests
- integration tests where appropriate
- regression tests for known bugs

## Security
- no secrets
- inputs validated
- permissions enforced
- sensitive logs protected
- agent tool permissions reviewed

## ML
- dataset version
- feature version
- model version
- evaluation protocol
- leakage checks

## Operations
- logs
- metrics
- health checks
- error handling

## Documentation
- README/API/architecture updated

## Release
- CI green
- migration tested
- changelog updated
- rollback known
