# DevOps & CI/CD

## Local commands
```bash
make install
make test
make lint
make format
make typecheck
make migrate
make dev
```

## CI
1. checkout
2. install
3. lint
4. typecheck
5. unit tests
6. integration tests
7. secret scan
8. dependency/security scan
9. Docker build
10. publish only from protected branches/tags
