# Research Protocol

## Hypothesis template
- hypothesis
- rationale
- dataset
- period
- asset/timeframe
- features
- target
- model
- validation
- cost assumptions
- risk assumptions
- failure modes

## Rules
1. Change one major variable at a time where possible.
2. Record all configurations.
3. Do not cherry-pick only successful experiments.
4. Keep a final untouched test period.
5. Report uncertainty and sample size.
6. Compare against simple baselines.
7. Perform sensitivity analysis.
8. Record failed experiments.

## Report
Objective, methodology, results, limitations, failure analysis, next hypothesis.

Never present a backtest as guaranteed future performance.
