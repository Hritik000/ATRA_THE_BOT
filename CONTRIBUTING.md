# Contributing to ATRA

Thank you for considering contributing to ATRA (AI Trading Research & Analysis Platform)! We welcome contributions from the community.

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/ATRA_THE_BOT.git
   ```
3. **Create a branch** for your feature or bugfix:
   ```bash
   git checkout -b feature-or-bugfix-name
   ```
4. **Make your changes**, ensuring you follow the coding standards and guidelines.
5. **Run tests** to ensure nothing is broken:
   ```bash
   make test
   ```
6. **Commit your changes** with a clear and descriptive commit message.
7. **Push to your fork** and submit a pull request.

## Coding Standards

- Follow the engineering principles outlined in `AGENTS.md`.
- Use type hints where applicable.
- Write clear, concise comments and docstrings.
- Keep functions small and focused.
- Ensure all new code is covered by tests where possible.
- Run `make lint`, `make format`, and `make typecheck` before submitting.

## Reporting Issues

Please use the GitHub issue tracker to report bugs or suggest features. When reporting a bug, include:
- Steps to reproduce the issue.
- Expected behavior vs. actual behavior.
- Any relevant logs or error messages.
- Environment details (Python version, OS, etc.).
